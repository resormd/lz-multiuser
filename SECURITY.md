# Security policy

Do not attach passwords, one-time codes, tokens or credential files to reports. For a suspected vulnerability, use the repository's private vulnerability reporting feature if the owner has enabled it. Otherwise contact the maintainer privately using contact details they explicitly publish; do not disclose exploit details in a public issue.

The extension delegates password verification to Windows runas. It does not change Windows account permissions, security policy, or authentication requirements. Organization restrictions take precedence. A successful process-owner check is not a guarantee of independent application credentials or a newly visible window.
